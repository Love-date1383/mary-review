سایت «برای مری»
=================

روش اجرا
--------
1) پوشه را از حالت ZIP خارج کن.
2) کل پوشه را با VS Code باز کن.
3) روی index.html راست‌کلیک کن و Open with Live Server را بزن.
   اگر Live Server نداری، با دوبار کلیک روی index.html هم سایت باز می‌شود.

تغییر سرعت تایپ
----------------
فایل script.js را باز کن. بالای فایل این بخش را می‌بینی:

const typingSpeed = {
  introTitle: 65,
  introText: 40,
  storyTitle: 40,
  storyText: 15
};

هرچی عدد بزرگ‌تر باشد، تایپ آرام‌تر می‌شود.
هرچی عدد کوچک‌تر باشد، تایپ سریع‌تر می‌شود.

تغییر متن‌ها
------------
همه‌ی متن‌های هفت صفحه در ابتدای فایل script.js و داخل const copy قرار دارند.

فایل‌های اصلی
-------------
index.html  ساختار صفحه‌ها
style.css   ظاهر، رنگ‌ها و حرکت‌ها
script.js   متن‌ها، سرعت تایپ و دکمه‌ها
assets      عکس‌های سایت

نکته
----
انتخاب مری و نوشته‌ی داخل کادر، فقط روی همان مرورگر ذخیره می‌شود و جایی ارسال نمی‌شود.

پایان‌های صفحه‌ی ششم
--------------------
دو گزینه‌ی «از نو شروع کنیم» و «یه حرف از خودت» هرکدام صفحه‌ی پایانی و دکمه‌های مخصوص خودش را دارند.
